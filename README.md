# Klinh Beauty – Front-end ReactJS

## Chạy trên macOS
Yêu cầu Node.js 18 trở lên.

1. Giải nén file ZIP.
2. Mở Terminal, chuyển vào thư mục dự án:
   `cd Klinh_Beauty_Frontend`
3. Cài thư viện:
   `npm install`
4. Chạy website:
   `npm run dev`
5. Mở địa chỉ Local Vite in ra trong Terminal (thường là http://localhost:5173).

## Có sẵn
- Trang chủ, sản phẩm mẫu, tìm kiếm và lọc danh mục.
- Trang chi tiết sản phẩm.
- Giỏ hàng: thêm/xóa/tăng/giảm số lượng, lưu localStorage.
- Đăng nhập mô phỏng, tài khoản, đặt hàng mô phỏng.
- Giao diện responsive cơ bản.

## Lưu ý
Chưa kết nối Backend Spring Boot, REST API, PostgreSQL hoặc Spring Security/JWT. Đăng nhập và đặt hàng chỉ mô phỏng trên trình duyệt. Sản phẩm/giá là dữ liệu mẫu, cần thay bằng dữ liệu thực tế của đồ án.
